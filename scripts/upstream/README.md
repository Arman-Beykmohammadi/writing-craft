# Vendored avoid-ai-writing (JavaScript)

These files are verbatim, byte-identical copies from [avoid-ai-writing](https://github.com/conorbronsdon/avoid-ai-writing) v3.36.0 (MIT License, Copyright (c) 2026 Conor Bronsdon), kept in their original relative layout so their `require` paths work unchanged; they are the reference that `tests/parity/run_parity.py` checks the Python ports in `scripts/aiw_*.py` against. `detector/patterns.js` is the detection engine (`analyzeText`), `detector/validate.js` the rewrite preservation validator, `detector/CATEGORIES.md` the engine's category map, `scripts/markdown-prose.js` the shared Markdown prose mask, `scripts/normalize-quotes.js` the quote normalizer, `scripts/check-style.js` the house-style mechanics checker (bare `--config` names resolve to `examples/*.json`, described in `examples/README.md`), `bin/avoid-ai-writing.js` the detector CLI and `bin/avoid-ai-writing-gate.js` the finding-count gate. Run them with Node 18 or newer from any directory, for example `node scripts/upstream/bin/avoid-ai-writing.js draft.md`, `node scripts/upstream/bin/avoid-ai-writing-gate.js --json draft.md`, `node scripts/upstream/detector/validate.js before.md after.md`, `node scripts/upstream/scripts/normalize-quotes.js draft.md --quotes curly` and `node scripts/upstream/scripts/check-style.js draft.md --config technical`. Do not edit these files; update them only by copying a new upstream release.
